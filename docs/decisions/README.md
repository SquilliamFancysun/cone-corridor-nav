# Decision records

Architecture decisions for v2, one file per decision. Each one records the choice, the context, what was given up, and what would make us revisit it.

An ADR isn't edited to say something different later. When a decision changes, its status becomes *Superseded* or *Reversed*, and a new ADR records the change. The checkpoint logs inside an ADR are the exception: they get filled in as the checkpoints are run.
